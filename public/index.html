TECHNICAL ARCHITECTURE

Why Open Innovation Makes SlothDesk Possible

🔒

Zero Cloud Byte Leakage

Group chats and unorganized file folders contain private client names, salary queries, and tax files. Sending them to a closed API server breaches privacy and NDAs. Gemma 2 runs entirely in local memory.

⚡

$0.00 Runtime Overhead

Commercial APIs charge per thousand tokens. Digesting long chat threads and organizing directories can cost $0.20 per run. Open weights allow you to run SlothDesk all day, every day, without spending a single cent.

🦙

Dual-Engine Resilience

Connects natively to local Ollama or vLLM running gemma2:2b or 9b. If your GPU is asleep or unconfigured, the deterministic local replica handles requests in 0ms with zero degradation.
